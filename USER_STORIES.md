# USER STORIES

- As a player, I want the camera to follow me smoothly so I never feel lost off-screen.
- As a player, I want the HUD inside the game area so I can read critical stats without scrolling.
- As a player, I want a visible human character with direction changes so movement feels alive.
- As a player, I want escalating danger across levels so the challenge feels meaningful.
- As a player, I want quick restart and pause controls so retrying feels frictionless.
